# Female abdominal muscle supplement

This update adds six individually selectable abdominal-wall muscles to the female reference atlas:
- Right and left rectus abdominis
- Right and left internal oblique
- Right and left transversus abdominis

The meshes are adapted from the supplied Ecorche source and modestly fitted to the female reference torso. Existing female external oblique muscles, all other female systems, and the complete male atlas are retained.

**Important limitation:** these six meshes are an anatomical approximation fitted to the female reference body, not female-specific scan data. The wider female muscle set remains the existing fitted BodyParts3D coverage; this patch does not claim to replace all 399 female muscle structures with female-specific anatomy.
